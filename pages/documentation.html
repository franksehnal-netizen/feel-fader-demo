Overview

Feel Fader is a compact USB MIDI controller with two faders, a detented roller and a button, designed for expressive control of orchestral and other virtual instruments – typically Expression (CC 11) and Dynamics (CC 1) on the faders and articulation switching on the roller.

It works as a class-compliant MIDI device without drivers. The web configurator lets you change what every control sends; the configuration is stored on the controller itself, so it works the same on any computer.

Configurator requirements

  • Google Chrome or Microsoft Edge on a desktop computer (Windows, macOS or Linux). The configurator uses Web Serial and Web MIDI, which other browsers do not support.
  • Feel Fader connected by a USB cable that carries data (not a charge-only cable).
  • Nothing to install – the configurator runs in the browser. You do not need the configurator to play; the controller keeps its configuration.

Getting started

  1. Connect Feel Fader to your computer via USB.
  2. Open the configurator and click Connect & load. Allow access to the device when the browser asks. The configurator reads the current configuration from the controller.
  3. Change what you need – faders, roller, button, banks.
  4. Click Send to device to save the changes to the controller.

Faders

Each fader sends a MIDI CC on a channel you choose (by default Expression CC 11 and Dynamics CC 1). The faders on screen mirror the hardware – they are display only and cannot be dragged.

Fader response (under Device) sets how the controller filters both faders:

  • Immediate – direct response for precise performance,
  • Balanced – natural control with subtle filtering (default),
  • Smooth – gentle glide for long expressive moves.

Roller

The roller has four modes, set per bank:

  • Articulation – steps through articulations (UACC). For Spitfire libraries, set the plugin's articulation lock to "Locked to UACC".
  • Keyswitch – sends MIDI note keyswitches on the configured channel. Click a piano key or drag across a range; the roller steps through the selected notes. Reorder long sequences by dragging rows or with Alt + arrow keys.
  • Navigation – sends a keyboard key per step (e.g. arrow keys) to navigate your DAW. Requires Keyboard (HID).
  • Relative CC – sends a relative step (value 1 = up, 127 = down) on the configured CC and channel, for external MIDI processing such as a per-track keyswitch mapper.

Button

  • Short press – switches to the next bank.
  • Long press (0.5 s or longer) – sends a key combination you define, e.g. play/stop or a DAW shortcut. Requires Keyboard (HID).

Banks

A bank is a complete setup of all controls. You can define up to 8 banks and switch between them with the button. Bank names and icons are saved in the browser and, with firmware 1.1.0 or later, also on the controller, so they follow it between computers.

In the configurator, the highlighted tab is the bank you are editing; a small green dot marks the bank currently active on the hardware. Library setups show a preview before changing the bank. Built-in setups are starting points – check them against the exact library patch and version.

Keyboard (HID)

When Keyboard (HID) is enabled under Device, Feel Fader can also send keystrokes like a computer keyboard. It is required for the Navigation roller mode and the button long-press macro. When it is off, the controller sends MIDI only.

Device settings

  • Firmware and Serial – the firmware version and serial number of the connected controller.
  • Your name – optional, up to 24 characters, saved on the controller; the configurator greets you by name when it connects.
  • Keyboard (HID) – see above.
  • Fader response – see Faders.

Firmware updates

When a new firmware is available, a dot appears next to Device and an Update button appears in the device settings. The update is installed from the configurator; keep the controller connected until it finishes. In-app updates are available from firmware 1.3.0. [Older firmware – how to update? Contact support?]

Backup, import and reset

Under Device › Backup & reset you can Export the full controller configuration to a .json file, Import it back (e.g. on another controller) or Reset it to factory defaults. Saved library setups can be exported and imported separately.

MIDI diagnostics

Under Device › MIDI diagnostics you can inspect the active bank mapping, the last received MIDI event, firmware, keyboard (HID) state and configuration checksum, or copy a support snapshot to the clipboard to send to us.

Troubleshooting

  • "Web Serial not supported" – open the configurator in Chrome or Edge on a desktop computer.
  • The controller is not found – try another USB cable (it must carry data) or another USB port, and close other browser tabs with the configurator open.
  • Changes have no effect – click Send to device; edits are only saved to the controller when sent.
  • Still stuck? – copy a support snapshot (MIDI diagnostics) and write to support@acoustic-empire.cz.
